# Visão Geral do Projeto

Extraído do arquivo principal `GEMINI.md`.

## 🚀 O Ecossistema
O **Soil Mineralogy AI** é um sistema RAG multimodal avançado.

### Componentes Principais:
1. **Multimodal Live RAG (Voz):** Conversação em tempo real com a especialista "Zé".
2. **Desktop App (Electron):** Interface visual para gestão de documentos.
3. **CLI Text RAG:** Consultas rápidas via terminal.

## 📂 Estrutura de Diretórios (Raiz)
- `src/`: Núcleo do sistema (FastAPI, Engine).
- `docs/`: Repositório de PDFs técnicos.
- `desktop/`: Código do app Electron.
- `obsidian/`: Este vault de conhecimento.

## 🛠️ Tecnologias
- Google Gemini (Flash Live)
- LangChain & ChromaDB
- FastAPI & Electron
